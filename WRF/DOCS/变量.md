## 常用变量
风场：U、V、W、U10、V10
温压湿：T2、Q2、PSFC、P、PB、QVAPOR
云降水：CLDFRA、QCLOUD、QRAIN、QICE、QSNOW、RAINC、RAINNC
地表过程：TSK、HFX、LH、GRDFLX、PBLH
辐射：SWDOWN、GLW、OLR
土壤：TSLB、SMOIS
地理静态场：XLAT、XLONG、HGT、LANDMASK、LU_INDEX。


## 水汽、云、降水、水凝物
QVAPOR：水汽混合比。
QCLOUD：云水混合比。
QRAIN：雨水混合比。
QICE：云冰混合比。
QSNOW：雪混合比。
QGRAUP：霰混合比。
QNICE：冰晶数浓度。
QNRAIN：雨滴数浓度。
CLDFRA：云量/云分数。
RAINC：累计对流降水。
RAINSH：累计浅对流降水。
RAINNC：累计网格尺度（非对流）降水。
SNOWNC：累计网格尺度雪和冰。
GRAUPELNC：累计网格尺度霰。
HAILNC：累计网格尺度冰雹。
SNOW：雪水当量。
SNOWH：物理雪深。
SNOWC：积雪覆盖标志。
ACSNOM：累计融雪量。
SR：冻结降水比例。

## 近地面诊断量
PSFC：地面气压。
T2：2 米气温。
TH2：2 米位温。
Q2：2 米水汽混合比。
U10 / V10：10 米风的 U / V 分量。
U10E / V10E：MYJSFC 方案给出的特殊 10 米风。
TSK：地表皮肤温度。
UST：摩擦速度 u*。
PBLH：边界层高度。


## 三维动力与基本状态量
U / V / W：三维 x / y / z 风分量。
PH / PHB：扰动位势 / 基态位势。
P / PB：扰动气压 / 基态气压。
P_HYD：静力气压。
MU / MUB：柱积分干空气质量的扰动项 / 基态项。
PC / PCB：也是柱积分干空气质量的扰动项 / 基态项。
T：扰动位温 theta - T0。
THM：湿位温扰动或干位温扰动，取决于模式选项。
P_TOP：模式顶气压。
P00：基态气压。
T00：基态温度。
P_STRAT：平流层底部的基态气压。
TLP：基态直减率。
TISO：基态温度转为常值时的温度。
TLP_STRAT：平流层中的基态直减率。
F / E：科氏参数中与纬度有关的正弦项 / 余弦项。


## 垂直坐标、层厚、混合坐标系数
ZNU / ZNW：η 坐标的半层（质量层）/ 全层（w层）值。
DN / DNW：相邻半层 / 全层之间的 d(eta)。
RDN / RDNW：对应的 d(eta) 倒数。
FNM / FNP：垂直伸缩权重（upper/lower weight for vertical stretching）。
C1H / C2H / C3H / C4H：半层混合垂直坐标系数。
C1F / C2F / C3F / C4F：全层混合垂直坐标系数。
CF1 / CF2 / CF3：二阶外推常数。
CFN / CFN1：外推常数。
ZETATOP：模式顶的 zeta 值。
RESM：小时间步的时间权重常数。
这些量主要是数值坐标/积分辅助量，一般不作为天气诊断场直接解释。
