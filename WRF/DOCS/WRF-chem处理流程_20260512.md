## chem 模块注意点

完整空气质量不能只靠 ERA5。你至少需要：

类型	常见文件	说明
气象初始/边界	wrfinput_d0*, wrfbdy_d01	ERA5 → WPS → real.exe
人为源	wrfchemi_*	MEIC、EDGAR、HTAP、CEDS 等转换
生物源	wrfbioemi_d0* 或在线 MEGAN	取决于 bio_emiss_opt
火点源	wrffirechemi_d0*	FINN、GFAS 等
化学初始/边界	修改后的 wrfinput_d0*, wrfbdy_d01	常用 mozbc 从 CAM-chem/MOZART 生成

&chem 的机制要和排放物种对应。例如：

&chem
 chem_opt                            = 8, 8, 8,       ! 例：CBMZ + MOSAIC
 emiss_opt                           = 4, 4, 4,
 emiss_inpt_opt                      = 102, 102, 102,
 io_style_emissions                  = 2,

 gas_drydep_opt                      = 1, 1, 1,
 aer_drydep_opt                      = 1, 1, 1,
 bio_emiss_opt                       = 0, 0, 0,
 biomass_burn_opt                    = 0, 0, 0,

 phot_opt                            = 2, 2, 2,
 chemdt                              = 1.0, 1.0, 1.0,
 photdt                              = 30, 30, 30,

 have_bcs_chem                       = .true., .true., .true.,
/
